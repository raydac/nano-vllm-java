## 2. Architecture & Technical Discoveries
- **Standing rule:** JDK-only runtime (Java 21+, optional Vector API). No third-party libs in library/sample JARs (test-scoped OK). TornadoVM is optional Maven deps (`tornado-api` provided, `tornado-runtime` runtime, both `optional`) — not transitive for consumers. No JNI/JNA/FFM/CLI for inference or G2P. ONNX/GGUF/safetensors parsed in Java.
- Load: `ContainerTransport` → `ArchitectureProcessor` (Causal / Embedding / Speech / Synthesis) bind → fill → create. Whisper = HF safetensors only; Piper = ONNX initializers + sidecar JSON (no chat/BERT remap). No Gemma3+Gemma4 parent.
- Share `LlmModel` / `PreparedRag`; one `LLM` is not concurrent-safe for generate (`cancel()` is). Close engines before model. `LlmModel` is `abstract sealed` → hidden `LlmModelImpl`. Peer graphs: `CausalLM` / `EmbeddingEncoder` / `SpeechToText` / `TextToSpeech`. Non-chat engines skip KV (`numKvcacheBlocks` 0) — Piper used to overflow `int` on a large heap.
- Matmul: builder `cpuThreads` wins over `-Dnanollvm.cpu.threads`. Default = process-wide daemon pool; `.dedicatedMatmulPool()` owned and shut down on close; `.matmulExecutor` caller-owned; `.disableMultiCpu()` / 1 thread = sequential. Last shared-pool checkout CAS-es to null and `shutdownNow()`.
- `LLM` owns one `Random` (unseeded, or seed `1L` for synthesis; `Builder.random`). Injected into Sampler + Piper VITS. Generate lock is the only exclusive engine lock. Lifecycle flags `AtomicBoolean`; no `volatile`/`synchronized`/`ThreadLocal` in the tree. `ConvStateArena` is a plain `HashMap` (generate-thread confined).
- ONNX: initializers only; payload field 9 or 13; MatMul B `[in,out]` → Linear `[out,in]`; `onnx::MatMul_*` remapped by node path. FLOAT/FP16/BF16/DOUBLE load; skip int/bool/string/complex; fail on float8/nibble. BERT prefixes are structural (`*.embeddings.` / `*.encoder.`). Conv vs ConvTranspose weight axes differ; spatial attrs live on `ConvLayout` from the consuming node (not voice-name guesses). Zero/missing ONNX `pads` do not override fused PyTorch padding.
- Piper G2P: `dictsource` (`*_list`/`*_rules`) first, then compiled `phontab`+`{lang}_dict` (listed words **and** `$N` stress), else letter-to-sound. Phoneme map uses IPA `ɡ` (id 66), not ASCII `g`. English: `@2`/`@5` → schwa; en-us remap `ɹ`/`ɚ`/`ɑː`. Russian: letter groups A/B/C/F/G/H/Y, palatalization, vowel reduction, destressing. VITS reverse uses graph dilations; Irina is ResBlock2 `convs.0/1`. Hot path: identity-mask skip, channel-major LayerNorm, SIMD dots.
- Whisper: greedy multilingual; incremental decoder self-attn KV; Bluestein FFT log-mel + sparse mels + optional parallel STFT; 30 s chunks in place. `LlmInSound.ofWav` / `ofPcm`; `Locale` null/ROOT = auto.
- Gemma 4 text QAT: flatten `text_config`; skip towers; packed int2/4/8 + SRQ; PLE after MLP; KV share; RMS `onePlusWeight=false`; `<|turn>` chat. Shards > 2 GiB use positioned `FileChannel`; ≤ 2 GiB copy into heap so close can drop them.
- GGUF: packed default; late unpack when no other engine is live. Chat `qwen3` is unfused `blk.N.*`. Gemma/Llama GGUF rejected.
- Unigram (XLM-R / E5): Viterbi + HF/SP charsmap; wrap accepts `<s>`/`</s>` and `[CLS]`/`[SEP]`.
- Dense RAG: index embeds sequential unless caller `Executor`; each job uses `MatmulRuntime.sequential()` (do not nest the pool). Query cosine is brute-force. `PreparedRag`/`DenseRagIndex`/`HybridRagIndex` shareable after build; `RagSession` is not.
- `TEXT_DEBUG` off unless `emitDebugPrompts(true)` (Example `--debug`). RAG corpus/advisor notes are trusted prompt input.
- HF `curl -C -` on a complete file → HTTP 416; `models/_curl_resume.sh` / `.ps1` treat 200/206/416 as success.
- SpotBugs `EI_EXPOSE_REP*` on tensors/KV/packed records is by design. Packed release is `packed.length == 0`. Props = `nanollvm.*` / `NANOLLVM_*` only.
- JPMS exports: `models` / `llm` / `chat` / `rag` / `tokenizer` / `utils` / `exceptions`. Hidden: `engine` / `layers` / `tensor` / `internal` / `prompts` / `models.internal` / `models.llmcontainer` / `models.llmarch`. `ModuleExportsTest` locks this.

## 3. Technical Debt & Refactoring
- Attention O(n²); no float16 / TP / CUDA; most HF safetensors still FP32; fused packed dequant-dot still open
- RMSNorm / LayerNorm / Sampler still sequential over tokens or logit rows
- Optional GGUF: mmap; smaller default KV; ModelFileSource still rejects ONNX `external_data`
- No ANN / vector DB; no ONNX QDQ/int8; no LFM2-from-ONNX
- **Java Senior (2026-08-27):** narrative `//` in `Transformer` / `LLM`; some interface params missing `final`; `Example.ModelChoice` holds `Optional<Path>`. Keep array/`for` on hot numeric paths (tensor, sampler, mel, VITS, KV packing).

## 5. Known Issues & Limitations
- CPU-only; weights not in git; LFM2 needs large heap. Security: `security_audit.txt` — parsers/corpus capped; RAG mixes corpus into prompts by design.
- Closing `LlmModel` while an `LLM` still holds the graph leaves dense weights reachable until that LLM closes.
- BERT HF safetensors still rejected. xlm-roberta-base fill-mask mean-pool is anisotropic (unrelated cosine often ~0.99); `Example` Classify is centered prototypes, not a Hub head. Use E5/GTE for retrieval.
- Gemma 4 vision/audio, GGUF Gemma 4, MoE out of scope. Whisper: no MP3/VAD/beam/timestamps; no CTranslate2/GGUF/ONNX. Piper: no streaming/SSML/multi-speaker picker; compiled espeak rules bytecode is not a full VM; packaged `ru_dict` omits some lemmas (`это`, `мама`).
- Tests skip via `OptionalModelAssumptions` / `SampleModelAssumptions` when local weights or `./rag` are absent. Packed gte-small Q2_K is slow if left packed.
- Tiny-LLM-ONNX is a toy (incoherent text, 1024 context). Tiny greedy Qwen3+RAG can still invent a famous book despite `RagPrompts.GROUNDING`.
- Piper alphabet recitation follows espeak *word* entries (`в`/`с` short, `б` = “бы”). English secondary `ˌ` on function-adjacent words still approximate.

## 6. Open Questions & Pending Decisions
- Piper vs full espeak: compiled rules VM, `$`/`J`/`#`/`V` atoms, `langopts.numbers`, full phoneme programs — stay out of the Apache JAR (no GPL sources, no JNI).
- Fold Sampler deeper into Transformer? BM25F? HF safetensors LFM2? Broader ONNX remaps for exotic exports?
- Fara / Qwen3.5 (`qwen3_5`) stay unsupported (fail fast). Gemma 4 multimodal / MoE stay out of scope.

## 8. User Advice and Recommendations
- Pure Java only; no JNI. Hot-path arrays/`for`, not Streams (tensor, attention, sampler, STFT/mel, VITS, KV).
- README stays on the last shipped version — never write SNAPSHOT into badge/coords/JAR names. After a release, `description.md` matches that version; during SNAPSHOT it may lead README. Whisper/Piper README snippets stay short (API only); full programs live in the sample classes.
- Document Maven as `mvn`; this machine uses `mvn22`.
- New public API in **1.3.1-SNAPSHOT** gets `@since 1.3.1`; do not retag older members. Do not vendor GPL Piper/espeak sources.
- `LLM.builder` for every kind; `.deterministic()` for greedy (not `temperature(0)`). Server: `.dedicatedMatmulPool()`, `.matmulExecutor(appPool)`, or `.disableMultiCpu()` — do not rely on the process-wide pool. One `LLM` per in-flight generate; share `LlmModel`. `ResourceLimits.setCurrent` is JVM-global.
- Mix RAG origins on one `RagFactory.builder()`. Do not put hybrid indexing back on `AdvisorRagHelloWorld` / `RagTunerHelloWorld` unless asked.
- Think tags / chat specials: `open(path).thinkTags(…).chatSpecials(…)`; omitted keys fill `DEFAULT`. Streaming `TEXT_RAW` keeps specials; `streamTo` ignores it.
- Piper: `optionalData(ESPEAK_DATA, dir)` when data is not next to the voice; omit or leave missing — TTS still runs.
- Tiny-LLM-ONNX: `onnx/model.onnx` or `model_fp16.onnx`; skip community `*_q4*` / `*_int8*`.
