## 2. Architecture & Technical Discoveries
- Engine status via `EngineIo`; chat UI via `StreamPrinter` / session `streamTo`
- Gemma: no system role by default; long system+hello latches setup boilerplate
- Scheduler.`clear()` aborts in-flight seqs on cancel/timeout
- One LLM instance is not concurrent-safe for generate; `cancel()` is cross-thread

## 3. Technical Debt & Refactoring
- Attention O(n²); no float16 / TP / CUDA graphs
- Metaspace BPE simplified; optional chat_template.jinja in download
- Optional repetition penalty for tiny IT models

## 8. User Advice and Recommendations
- Document Maven as `mvn` (portable); on this machine the agent may invoke `mvn22`
- Prefer `ChatSession` for dialog; keep raw `generate` for completions
- Do not stack long Gemma system prompts — latch risk
- Keep I/O out of Config
- Educational guide: English `description.md` only — do not revive a Russian translation
- Prefer Stream API for declarative filter/map/collect; keep stateful scheduler/prefill and numeric kernels as loops
- User preference (global Java senior rule): Stream-first for collection work when a clear pipeline exists
- In `LLM`, keep `//` comments on business orchestration methods and their internal stage calls (generate/step/drive)
