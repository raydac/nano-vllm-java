## 2. Architecture & Technical Discoveries
- Engine status via `EngineIo`; chat UI via `StreamPrinter` / session `streamTo`
- Gemma: no system role by default; long system+hello latches setup boilerplate
- Scheduler.`clear()` aborts in-flight seqs on cancel/timeout
- One LLM instance is not concurrent-safe for generate; `cancel()` is cross-thread
- Share one `Model` across many `LLM`s; each LLM owns KV + scheduler; closing LLM does not unload Model
- Share one `PreparedRag` across many LLMs; `PassagePreparser` + inverted BM25 run at load, not per query
- Exported packages: root (Example/Bench), models, llm, chat, rag, exceptions, tokenizer, prompts, utils (`BundledModels`/`BundledRag`/`Json`/`NanoVllmProps`)
- Module-private: engine, layers, tensor, **internal** (loader/safetensors/gguf/Context); `models` also holds graph types (`CausalLM`, …) alongside public `Model` / `ModelFactory`
- `Model.network()` still returns `CausalLM` for same-module `Transformer` (documented non-stable; `models` package is exported)
- **GGUF→FP32:** Q4_K_M mixes Q4_K+Q6_K; 2D GGUF dims reversed to HF `[out,in]`; LFM2 norm is `token_embd_norm`; shortconv state keyed by `seqId`; `head_count_kv` is a per-layer array (0=conv) — use max>0 as GQA kv heads (not scalar fallback to 32)
- **CPU matmul parallel:** `VectorMath.configureCpuThreads(N)` splits `out` axis; default = `Runtime.availableProcessors()` for all models; `.cpuThreads(N)` / `.allCpuThreads()` / prop `nanovllm.cpu.threads`
- **LFM2 chat:** GGUF often omits `chat_template` — use ChatML when vocab has `<|im_start|>`; `invitesThinking=false` + `PLAIN_CHAT_SYSTEM` (Qwen think rules cause format-narration)

## 5. Known Issues & Limitations
- CPU-only; large float32 heap; weights not in git
- LFM2.5-2.6B GGUF needs ~16 GiB heap after Q4→FP32 (+ KV/JVM); default `-Xmx16g` in `.mvn/jvm.config`
- `Bench` used to hardcode `numKvcacheBlocks(256)` (~14 GiB KV for Qwen3-0.6B) → OOM at start; now sizes blocks from `numSeqs × ceil(maxModelLen/blockSize)` and skips warmup — still needs `MAVEN_OPTS=-Xmx8g` for the weights
- Gemma3-270M weak knowledge / paraphrase; first chat turn can be slow
- Tiny Gemma can still invent facts not in retrieved passages (mitigated: strict grounded prompt, compact-passage preference, temp clamp, isolateGeneration) — not eliminated on 270M
- Off-topic RAG replies (Java → Grimm class names) were weak BM25 leftovers (`one`/`by`/`text`) after OOV drop — mitigated by out-of-corpus gate (`unknown > known`) + overlap
- Qwen RAG with thinking on + low maxTokens can truncate after long `<think>` — Example uses 768 for Qwen; stub salvage remains in ChatSession

## 8. User Advice and Recommendations
- Document Maven as `mvn` (portable); on this machine the agent may invoke `mvn22`
- Prefer `ChatSession` for dialog; keep raw `generate` for completions
- Do not stack long Gemma system prompts — latch risk
- Keep I/O out of Config
- Educational guide: English `description.md` only — do not revive a Russian translation; keep §7a GGUF **format** (layout/dtypes) + chat/heap/cpuThreads in sync with code
- Prefer Stream API for declarative filter/map/collect; keep stateful scheduler/prefill and numeric kernels as loops
- LFM2 quality pass: drop unused ShortConv/ConvStateArena accessors; Lfm2MLP uses `Ops.siluAndMul(gate,up)` + `Ops.add`; GGUF vocab from token array (not bogus metaInt); rms eps via first present key
- User preference (global Java senior rule): Stream-first for collection work when a clear pipeline exists
- In `LLM`, keep `//` comments on business orchestration methods and their internal stage calls (generate/step/drive)
- Model = immutable loaded data; all thread/runtime state on LLM (`KvCacheArena`, scheduler, generate lock)
- IntelliJ “Reformat code” before commit can break fenced samples in `description.md` — project `.editorconfig` sets `ij_formatter_enabled = false` for `*.md` (EditorConfig support must stay enabled in IDEA)
- Method/constructor parameters that are not reassigned must be `final` — in global `java-senior` rule; applied across `src/` (generics second pass); record headers excluded; reassigned params refactored to locals (`AssistantParts`, `Gemma3`/`Qwen3` decoder, `ChatPrompts`)
