## 1. Implementation Progress
- Maven `1.0.0-SNAPSHOT`; enforcer Java `[21,)`, Maven `[3.9,)`; JPMS module `com.igormaznitsa.nanollvm`; POM description = CPU LLM inference library (not an app / not a full vLLM port)
- **ResourceLimits** (exported utils): process-wide defaults + builder; RAG/PDF/JSON/GGUF/safetensors/corpus/history budgets; overridable via `ResourceLimits.setCurrent` or `RagLoadOptions.withResourceLimits`
- CausalLM: Qwen3 + Gemma3 + LFM2 (GGUF); tokenizers GPT-2 BPE / Metaspace / GGUF-embedded
- **GGUF:** packed by default; `LlmModelFactory.make(path, io, true)` unpacks at load (mmap→float32, no packed heap); `LLM.Builder.allowUnpackParameters()` late-unpacks packed models (releases bytes); `Lfm2ForCausalLM`; Example menu #3
- Library: `LlmModelFactory.make` → shared immutable `LlmModel`; `LLM.Builder` (warmup **off** by default); `GenerationStats` on `GenerationOutput` / `ChatReply`; `ChatSession` + `LlmListener`; helpers `chat`/`chatOnce`/`complete`; `cancel` + timeout; `exceptions.*`
- **Advisors:** `advisors(LlmAdvisorMixer, LlmAdvisor…)`; unique non-blank names at build; one batched `generate`; `AdvisorResponse(name,text)`; mix via mixer with `ChatHistory`; Example uses `LlmAdvisorMixer.defaults()`
- Engine: `Transformer` owns per-LLM `KvCacheArena` (+ optional `ConvStateArena`) and an explicit step `Context` (no ThreadLocal); `MatmulRuntime` per `LLM`, bound on that Context each step; `VectorMath` = stateless float primitives only
- `Sequence` carries its own `blockSize` from `Config` (no process-wide registry)
- `LLM.generate` / `close` use `ReentrantLock` (no `synchronized`)
- JPMS: exports models/llm/chat/rag/exceptions/tokenizer/utils; non-exported `models.internal`, `prompts`, samples, engine/layers/tensor/internal; library JAR has no `Main-Class`; `NanoLlvmProps` prefers `nanollvm.*` (legacy `nanovllm.*`)

- **Samples packaging:** `BundledModels` / `BundledRag` → `samples.utils` (not library API); README Hello World mirrored as `samples.LogTriageHelloWorld`
- **RAG:** `RagFactory` → `PreparedRag` (inline BM25 + passage prep + `Passage` record); package-private `CorpusLoader` for chunking; `RagSession` nests `UserMessage`, `QueryRewrite`, `Retrieval`; public API ~10 types in `rag/` (+ `PdfTextExtractor`)
    - Docs: English `description.md` (§7a GGUF kernels/in-place dequant, §15 call chain, §16 map, §17 RAG, ch.10 math); README GGUF / features aligned; ch.16 paths audited
- Demo RAG corpus under `rag/` is `.md`/`.txt` only; `rag/*.pdf` is gitignored (local/temporary PDFs, not project assets or test fixtures)


## 2. Architecture & Technical Discoveries
- Share one `LlmModel` / `PreparedRag` across many `LLM`s; one LLM not concurrent-safe for generate (`cancel()` is cross-thread); `Scheduler.clear()` on cancel/timeout
- Advisors: same `LLM.generate` batch; prior *user* turns only; mixer gets `ChatHistory` + `List<AdvisorResponse>`; default mixer inserts notes into facts; salvage uses grounded notes from original prompt
- `extractContextBlock` ends at `\nIf Context` / answer markers so instruction text is not treated as Context terms
- Exports: models, llm, chat, rag, exceptions, tokenizer, utils (`NanoLlvmProps`); private: samples (+ utils for local models/rag), engine, layers, tensor, internal, prompts, `models.internal` (`LlmModelAccess`)
- Demo path helpers: `samples.utils.BundledModels` / `BundledRag` — not shipped as public API (weights/corpus not in JAR)
- Engine obtains `CausalLM` via `LlmModelAccess.resolveNetwork` (public `LlmModel.network()` removed)
- GGUF: packed by default; load-time unpack via `make(..., true)`; late unpack releases packed bytes; per-tensor `LinearKernel` / `EmbeddingKernel` = dense or one packed holder + dequant lambda (type chosen in `of()`)
- Format splits stop at weight touchpoints: activations/KV/RMSNorm/Attention/`FloatKernels` are always F32 — further “format variants” of those classes buy nothing. `GgufDequant.dequantizeRange` now decodes Q4_0/Q8_0/Q4_K/Q6_K blocks straight into `dst` (one-block scratch only for mid-block edges); next optional win is fused packed GEMM
- Optional next GGUF perf: mmap weights (no `byte[]` copy); FP16 / smaller default KV; fused packed GEMM without row scratch

- LFM2 chat: no `chat_template` in many GGUFs → ChatML if `<|im_start|>` in vocab; `invitesThinking=false` + `PLAIN_CHAT_SYSTEM` (Qwen think rules cause format-narration)
- Gemma: no system role by default; long system+hello latches boilerplate
- Engine status + chat text share `LlmListener` / `LlmTextKind` (`STATUS_*` + `TEXT_*`); `.listen(...)` on LLM / factories; no EngineIo
- `TEXT_DEBUG`: ChatSession always emits prepared model-user text after advisors; CLI `streamTo` prints `debug>` lines; advisor notes use advisor name (`TEXT_ADVISOR_NOTE` + `advisorName`)
- Off-topic RAG: any longest-tier contentful OOV ⇒ outside (blocks `about`-only BMW→LRRH hits)
- RAG session: short turns with prior → rewrite only if follow-up alone has no hits; NONE/empty → Prior+follow-up fallback (not abort); `PreparedRag.retrieve` re-ranks by coverage + length; helpers in `RagSession.Retrieval`; `RagIndex.isOutsideCorpus` on indexes


## 3. Technical Debt & Refactoring
- **API surface (pre-1.0):** path LLM ctors/builders and public tick API removed (SNAPSHOT: no deprecation period); ChatReply/`AssistantParts` demotion, `RagSession.open(ChatSession)` rewrite, Config KV setter package-private, defensive returns, JavaDoc/thread contracts
- Attention O(n²); no float16 / TP / CUDA; GGUF packed by default (`allowUnpackParameters` → float32); HF safetensors still FP32
- PDF RAG: pure-Java extractor; Cyrillic inflection keys; PDFBox test-scoped
- `Sequence` KV `blockSize` is per-sequence (from `Config`); `Config` sealed at build (no post-load setters); matmul uses shared lazy or custom `ExecutorService` (not per-LLM owned pools)
- No `ThreadLocal` / `synchronized` in library code: step `Context` is explicit; generate exclusion via `ReentrantLock`; `MatmulRuntime` shared pool remains `AtomicReference` CAS; `FloatKernels` / tokenizer byte maps are immutable singletons
- LFM2 GGUF tokenizer heuristics may need per-export tuning
- Advisors: Example wires named `LlmAdvisor`s by arch on `LLM.Builder` — Gemma/Qwen on, LFM off
- Remaining polish (optional): thin unused Config knobs (`gpuMemoryUtilization` / `enforceEager`); drop legacy `nanovllm.*` after notice

## 5. Known Issues & Limitations
- Security (see `security_audit.txt`): defaults now cap inflate/CMap/safetensors header/corpus/JSON/GGUF string dims; raise via `ResourceLimits` / `RagLoadOptions.withResourceLimits`. RAG mixes corpus into prompts by design (README trust boundary); `ChatSession.emitDebugPrompts(false)` to suppress TEXT_DEBUG
- Pre-1.0 optional: thin CPU-parity Config knobs; drop legacy `nanovllm.*` after notice
- CPU-only; HF safetensors still float32 heap; GGUF weights packed; weights not in git
- LFM2.5-2.6B: packed weights ~disk size; default `-Xmx16g` still used for KV/scratch headroom
- Bench auto-sizes KV blocks; still needs `MAVEN_OPTS=-Xmx8g` for weights
- Gemma RAG: simple withContext/withoutContext prompts; advisors on for Gemma/Qwen demo; Example topK=2 (Gemma) / 4 (default), 128 tok, 900 chars
- Bugfix: `.diagnostics()` after `.streamTo()` used to drop `printSink` (lambda compose) → missing `assistant>` labels / glued turn stats
- Demo `rag/` is English Grimm/LRRH only
- Off-topic RAG: no stopword lists — length + DF/OOV (any longest-tier contentful OOV ⇒ outside); select by length then IDF; drop zero-coverage hits
- Boilerplate salvage prefers grounded advisor notes from salvage list
- Short follow-ups: rewrite skipped when alone has hits; NONE/empty → Prior+follow-up fallback
- Qwen RAG + thinking + low maxTokens truncates after `<think>` — Example uses 768
- Advisors add latency (one batched generate for all roles); matmul pool parallelism applies inside that batch
- CPU matmul pool is process-shared (lazy) or caller-provided via `LLM.Builder.matmulExecutor`

## 8. User Advice and Recommendations
- Document Maven as `mvn` (portable); agent on this machine may use `mvn22`
- Prefer `ChatSession` for dialog; raw `generate` for completions; keep I/O out of Config
- Optional: use as return only (never method params) — `Retrieval.queryAfterRewrite` takes nullable `String`
- Optional `.matmulExecutor(ExecutorService)` for custom matmul workers; omit for lazy shared pool; never shut down by `LLM.close()`
- Do not stack long Gemma system prompts (latch risk)
- English `description.md` only — no Russian translation revive
- Stream-first for filter/map/collect; keep scheduler/prefill and numeric kernels as loops
- Keep `//` stage comments on LLM / Transformer orchestration methods
- LlmModel = immutable data; all runtime state on LLM
- IntelliJ reformat can break `description.md` fences — `.editorconfig` disables markdown formatter (`ij_formatter_enabled = false`)
- Unreassigned method/ctor params must be `final` (java-senior rule; records excluded)
- Do not add temporary large PDFs under `rag/` into the repo or tests — keep local-only (`rag/*.pdf` gitignored); use in-test fixtures for PDF/Cyrillic coverage
